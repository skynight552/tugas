# BelanjaYuk

Project Expo Router dengan UI yang diperbarui.

## Menjalankan
1. `npm install`
2. `npx expo install --fix`
3. `npx expo start`

Untuk web: `npx expo start --web`

## Catatan
- Data belanja tetap disimpan secara lokal menggunakan AsyncStorage.
- Fitur CRUD, checklist, foto barang, dan pencatatan lokasi tetap dipertahankan.
- Tampilan beranda memiliki pencarian, filter status, filter kategori, ringkasan estimasi, dan progress belanja.
- `react` dan `react-dom` disamakan pada versi 19.1.0 untuk Expo SDK 54.
